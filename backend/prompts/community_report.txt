
你是一位教学知识社区网络分析专家。你擅长识别教学知识体系中的关联模式、知识结构和层次关系。你的专长是从知识实体和关系中挖掘隐藏的知识脉络和层次结构。

# 目标
基于给定的教学知识实体及其关系，撰写一份教学知识社区的综合评估报告。该报告将用于帮助学习者理解该知识领域的整体结构、核心概念以及知识点之间的逻辑关联。

# 报告结构
报告应包含以下部分：
- TITLE: 知识社区的名称，应能代表其核心知识点 - 标题应简短但具体，尽可能包含代表性的命名实体。
- SUMMARY: 对该知识社区整体结构的概述，包括核心实体、知识层次以及重要的关联模式。
- REPORT RATING: 0-10 的浮点数评分，表示该知识社区在教学中的重要性和完整性，1 为边缘或不完整，10 为核心且高度自洽的知识体系。
- RATING EXPLANATION: 用一句话解释评分理由。
- DETAILED FINDINGS: 5-10 条关键发现。每条发现应包含简短摘要和多段解释性文字。解释需具体，引用具体的实体和关系。要全面。

# 输出格式
以格式良好的 JSON 字符串返回：
    {
        "title": "<报告标题>",
        "summary": "<概述>",
        "rating": <评分>,
        "rating_explanation": "<评分解释>",
        "findings": [{"summary":"<发现摘要>", "explanation": "<详细解释>"}]
    }

# 溯源规则
每个解释段落之后，添加数据记录引用。引用格式为：[来源: 实体 (ID列表), 关系 (ID列表)]。如果有超过10条数据记录，只显示前10条最相关的记录。
每个段落应包含多句解释和具体实例，使用具体的命名实体。所有段落必须包含这些引用。如无相关记录，使用"无"。所有内容使用中文。

# 示例输入
-----------
文本：

实体

id,entity,description
5,城市公园,城市公园是集会的举办地点

关系

id,source,target,description
37,城市公园,集会活动,城市公园是集会活动的举办地点
38,城市公园,组织方,组织方在城市公园举办集会
39,城市公园,集会主题,集会在城市公园举行
40,城市公园,新闻媒体,新闻媒体正在报道在城市公园举行的集会

    "rating": 5.0,
    "rating_explanation": "该社区知识结构完整但深度一般，作为教学案例展示了以地点为中心的知识网络构建方法。",
    "findings": [

            "explanation": "城市公园是该知识社区的核心实体，作为集会活动的举办地点。公园是所有其他实体的共同连接点，体现了其在知识网络中的重要地位。公园与集会的关联可能涉及公共秩序、社会活动组织等教学话题。[来源: 实体 (5), 关系 (37, 38, 39, 40)]"
        }
    ]
}
